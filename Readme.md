## Objectifs

- Me préparer à l'Advent of Code 2026
- Renforcer mes compétences en Python et en programmation
- 100% de ligne de code manuel, aucun generation ou reference IA lors de la 1ere solve

## Workflow

1. Télécharger l'input du jour avec le script `fetch`
2. Copier l'exemple de l'énoncé dans `example.txt`
3. Ouvrir le template de la journée et importer la toolbox
4. Rédiger le pseudo-code, puis implémenter la solution
5. Lancer le programme via l'entrée standard :

   ```bash
   python dayXX.py < example.txt
   python dayXX.py < input.txt
   ```

## Après chaque résolution

- Améliorer le workflow, le template et la toolbox
- Analyser ce qui a fonctionné et ce qui n'a pas fonctionné
- Lister les points d'amélioration et les leçons à retenir
- Identifier comment améliorer mon processus de réflexion pour éviter les mêmes erreurs
- Refactoriser la solution dans un second fichier

## Données

Les inputs et les exemples ne sont pas versionnés, conformément à la demande d'Advent of Code
